The Modern Systems Landscape

Systems programmers have exceptional tools today. Here is why cfire takes a dedicated, pragmatic path focused on modern C++23.

01. THE ECOSYSTEM SPECTRUM

Distinct Strengths for Distinct Needs

Rust delivers unmatched compile-time borrow verification. Zig offers exquisite manual control over C-level primitives and custom allocators. Go provides unmatched velocity for networked services. Each represents a top-tier engineering choice for its domain.

02. THE C++23 PRODUCTION REALITY

The Enduring Power of C++

In game engines, audio DSP, robotics, LLM inference runtimes, and embedded kernels, modern C++ remains an unrivaled standard. Yet writing raw C++ still imposes daily friction: multiple initialization styles, implicit copy hazards, unannotated call-site mutations, and macro-heavy FFI bindings.

03. THE CFIRE PROPOSITION

C Heritage, Fire Velocity

The name cfire (pronounced like sapphire) pairs C (direct mechanical sympathy, raw performance, zero-cost abstractions) with modern fire (blazing developer velocity without forty years of boilerplate). It lowers 1-to-1 to human-readable standard C++23 with zero GC pauses, pure RAII, and 1-click CMake ejection.

Where cfire Simplifies Daily Systems Code

Compare error-prone C++ patterns against clean, self-documenting cfire syntax.

01. INTENT & MUTABILITY SAFETY

Call-Site Mutation Visibility

In raw C++, process(data); hides whether data is read-only or secretly modified in-place. In cfire, callers must write process(mut data), and the compiler rejects hidden side effects at compile time (cfire/MUT-CALLSITE). 

// cfire: Intent is explicit at definition and call site
fn increment(mut b: Box, amount: i32) {
    b.value = b.value + amount
}

mut my_box := Box{ value: 40 }
increment(mut my_box, 2) // OK: 'mut' marker mandatory
02. ERROR RECOVERY & DEFER

Fearless Error Propagation

C++ exceptions introduce hidden control flow and binary bloat, while std::expected requires verbose monadic chains. cfire fallible functions return T! with clean try, inline fallback or val, and deterministic defer. 

// cfire: Fallible operations with deterministic defer
fn load_config(path: str) -> Config! {
    mut f := try fs.open(path, "r")
    defer f.close() // Always runs on return or error
    payload := try f.read_all()
    return try json.parse[Config](payload)
}
03. ALGEBRAIC ENUMS & MATCH

Exhaustive Pattern Matching

In C++23, std::variant requires the cumbersome 6-line template<class... Ts> struct overloaded visitor pattern. cfire features first-class algebraic enums with concise slice and value pattern destructuring. 

// cfire: Tagged unions with exhaustive compiler checks
type Shape enum { Circle(f64), Rect(f64, f64) }

fn area(s: Shape) -> f64 {
    match s {
        Circle(r)    => { return 3.14159 * r * r }
        Rect(w, h)   => { return w * h }
    }
}
04. ZERO-FFI C/C++ INTEROP

Direct Clang AST Ingestion

Forget hand-written extern "C" wrappers, Cgo pointer marshaling, or bindgen scripts. cfire directly dumps Clang's JSON AST at compile time, caches header signatures, and automatically coerces string boundaries. 

// cfire: Ingest C/C++ headers directly with zero wrappers
import cpp "fast_hash.h"

fn main() {
    msg := "cfire systems language"
    // 'str' passes automatically as 'const char*'
    hash := cpp::fh_fnv1a(msg, msg.len())
    println("Hash: 0x{:x}", hash)
}

Get Started in 3 Steps

From zero to running your first high-performance systems service in under 60 seconds.

STEP 1

Build or Install

Clone and compile the pure C++23 compiler in seconds with zero external dependencies:

git clone https://github.com/gsandoval/cfire
cd cfire && make
STEP 2

Write `main.cf`

Create a clean, idiomatic service file with built-in stdlib:

package main

import "core:time"

fn main() {
    now := time.now()
    println("Hello from cfire! 🚀")
    println("Time: {}", now.format_rfc3339())
}
STEP 3

Run, Build or Eject

Execute immediately, compile a binary, or eject to CMake:

./cfire run main.cf
./cfire build main.cf -o my_service
./cfire eject main.cf ./standalone_pkg
