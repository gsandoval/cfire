ARCHITECTURAL STATEMENT · OCTOBER 2026

Why write 50 lines of C++ boilerplate when 6 lines of cfire compile to the exact same machine code?

cfire is an ergonomic, zero-cost systems language that emits standard, human-readable ISO C++23. It introduces Go-like syntax clarity and compile-time intent safety without requiring a garbage collector, a custom linker, or a foreign runtime.

01. INTENT SAFETY

Call-site Parameter Transparency

Function arguments specify exact semantics (in, mut, out, move). Call sites must mirror these intents, preventing accidental copies or silent mutations.

02. NATIVE C/C++ INGESTION

Zero-Friction Clang Bridge

Import C and C++ headers directly into cfire. The compiler runs Clang's JSON AST dump, extracts function signatures, and handles string pointer coercion automatically.

03. STANDALONE EJECTION

Hermetic CMake Portability

No vendor lock-in. Run cfire eject at any time to generate a 100% standalone CMake project with all companion C/C++ dependencies and ISO C++23 source code.
