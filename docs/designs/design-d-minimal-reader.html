Systems ergonomics without the runtime tax.

cfire is a modern programming language that compiles directly to ISO C++23. It eliminates C++ header chaos and implicit copying while maintaining raw metal execution speed.

$ curl -fsSL https://cfire.memo.engineer/install.sh | sh

How it works

cfire code lowers 1-to-1 to standard C++23. Tap below to see both sides.

package main

type Buffer struct {
    data: []u8
    len:  i32
}

// Intent qualifiers: in, mut, out, move
fn append_byte(mut buf: Buffer, byte: u8) {
    buf.data = append(buf.data, byte)
    buf.len = buf.len + 1
}

fn main() {
    mut b := Buffer{ data: [], len: 0 }
    // Call-site 'mut' is strictly mandatory:
    append_byte(mut b, 0x42)
    println("Buffer len={}, byte={:#x}", b.len, b.data[0])
}
#include "cfire_prelude.hpp"

struct Buffer {
    std::vector data{};
    std::int32_t len{};
};

// 1-to-1 ISO C++23 lowering with ZERO runtime overhead:
auto append_byte(Buffer& buf, std::uint8_t byte) -> void {
    buf.data.push_back(byte);
    buf.len = (buf.len + 1);
}

auto main(int argc, char** argv) -> int {
    auto b = Buffer{.data = {}, .len = 0};
    append_byte(b, 0x42);
    std::println("Buffer len={}, byte={:#x}", b.len, b.data[0]);
    return 0;
}

Why cfire?

1. Explicit Parameter Intents

Functions explicitly declare in, mut, out, and move. Callers must supply the intent qualifier, making mutability immediately obvious during code review.

2. Native Clang C/C++ Ingestion

Write import cpp "header.h". The compiler queries Clang's JSON AST dump directly, extracting type signatures and handling string conversions automatically.

3. Zero Runtime Overhead

There is no garbage collector, no hidden green threads, and no custom runtime library. cfire code executes as raw C++23.

4. Standalone CMake Export

Run cfire eject main.cf ./dist at any time. It outputs a complete, self-contained CMake project that compiles with standard Clang or GCC.
