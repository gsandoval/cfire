The Modern Systems Landscape

Systems programmers have strong alternatives today—from Rust and Odin to C++ transpilers like cppfront, Jakt, and Nim. Here is where cfire fits.

01. THE ECOSYSTEM SPECTRUM

Peers & Precedents

Rust provides full compile-time borrow checking. Odin and Zig offer explicit low-level control with clean package systems (core:*). cppfront (Cpp2), Jakt, and Nim show the value of lowering ergonomic syntax to C++.

02. THE C++23 PRODUCTION REALITY

Why Target Standard C++23

In game engines, audio DSP, robotics, and LLM runtimes, C++ remains the native ABI. Yet raw C++ imposes daily friction: implicit copies, unannotated call-site mutations, verbose sum types (std::variant), and complex build files.

03. THE CFIRE DIFFERENTIATOR

Ejectable C++23 + Tiered Stdlib

cfire combines Go/Odin-inspired syntax, 8 static intent and pattern-reachability checks, direct Clang AST header ingestion, and a tiered standard library—while guaranteeing a 1-command exit to standalone ISO C++23 + CMake via cfire eject.

Deterministic Architecture: Language Primitives

Standard C++23 RAII, static call-site intent rules, and zero-lock-in CMake ejection.

Get Started in 3 Steps

Build from source, run via Docker, or use the POSIX bootstrap script—then verify your toolchain with cfire doctor.

STEP 1

Build or Install

Compile the single-binary C++23 toolchain from source (or run in Docker) and verify host dependencies:

git clone https://github.com/gsandoval/cfire
cd cfire && make && ./cfire doctor
STEP 2

Write main.cf

Create a clean, idiomatic service file with built-in stdlib:

package main

import "core:time"

fn main() {
    now := time.now()
    println("Hello from cfire!")
    println("Time: {}", now.format_rfc3339())
}
STEP 3

Run, Build or Eject

Execute immediately, compile a binary, or eject to CMake:

./cfire run main.cf
./cfire build main.cf -o my_service
./cfire eject main.cf ./standalone_pkg
